# Buddy Terminal — GitHub snapshot

A snapshot mirror of the Buddy Terminal command center. The live version runs
privately in Muse and refreshes every 30 minutes; this repo holds pushed
snapshots only, so the numbers here are as of the timestamp on the page.

## What is in here

- `index.html` — one dark terminal screen: BTC, six-agent status, the official
  paper book (old funding-fade book), open paper positions, funding extremes,
  analyst candidates, dry-run notes, and recent closed paper trades.

## Rules this snapshot follows

- Paper only. No live trading, no API keys, no real orders anywhere in this
  project.
- The numbers are the paper book's own numbers, reported on a real basis
  (real Bybit funding rates, real 0.055% taker fees). They are not the owner's
  real-money positions.
- A candidate marked NO TRADE at market means exactly that. A real call still
  needs a confirmed close trigger in chat.
- The Small-$5 book is stopped and archived (bank $500.00, 0 trades, monitor
  off since 31 Oct 2026 23:11 WIB). It appears only as a stopped line.
- Nothing here is financial advice.
